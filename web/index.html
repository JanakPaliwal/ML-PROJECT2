About This Project

Mandi Price Prediction Using Machine Learning

Subject: DSC-17 Machine Learning | Data Source: agmarknet.gov.in

SDG 2: Zero Hunger SDG 12: Responsible Consumption Data: Agmarknet Portal
ML Concepts Used (DSC-17 Syllabus)
  • Preprocessing (Unit 2): Feature Scaling using StandardScaler, removing outliers and wrong data entries from Agmarknet records.
  • Linear Regression (Unit 3): Predicting price using a linear equation: y = w1*x1 + w2*x2 + ... + b. Uses gradient descent to find best weights.
  • Ridge Regression (Unit 3): Linear Regression with L2 regularization to prevent overfitting on small datasets.
  • k-NN Regressor (Unit 4): Finds the k most similar past market days and averages their next-week prices to make a prediction.
  • MLP Neural Network (Unit 4): Multi-layer perceptron with hidden layers, ReLU activation, and backpropagation algorithm for training.
  • Evaluation Metrics (Unit 3): RMSE, MAE, MAPE, and R2 Score to measure how good each model's predictions are.
